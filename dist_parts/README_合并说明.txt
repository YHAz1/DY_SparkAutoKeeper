# 分卷说明

本目录为打包版压缩包的分卷（GitHub 单文件 100MB 限制，故拆分为 5 卷）。

合并方法（Windows）：
  copy /b DY_SparkAutoKeeper_v1.0.0_win64.zip.part1 + DY_SparkAutoKeeper_v1.0.0_win64.zip.part2 + DY_SparkAutoKeeper_v1.0.0_win64.zip.part3 + DY_SparkAutoKeeper_v1.0.0_win64.zip.part4 + DY_SparkAutoKeeper_v1.0.0_win64.zip.part5 DY_SparkAutoKeeper_v1.0.0_win64.zip

合并后解压 DY_SparkAutoKeeper_v1.0.0_win64.zip，双击 app.exe 使用。

或使用下载工具（如 IDM）逐个下载后按顺序合并。
