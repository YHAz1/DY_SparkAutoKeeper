# DY_SparkAutoKeeper — 自动续火花工具

每天定时给指定好友发送 `[续火花吧]`，保持火花不断。纯本地运行，**非运行时段零进程、零性能占用**。

## 快速开始（打包版，无需安装环境）

1. 下载压缩包 `DY_SparkAutoKeeper_v1.0.0_win64.zip` 并解压
2. 双击 `app.exe` 打开设置面板
3. 首次使用：点「立即运行一次」扫码登录 → 之后自动复用登录态
4. 填入好友备注、设置发送时间，点「注册自启任务」

> 无数字签名，首次运行如出现 SmartScreen 警告，点「更多信息 → 仍要运行」。

## 功能

- 每日自动给 1 个或多个好友发送 `[续火花吧]`（输入文本自动转为火花表情）
- PyQt5 设置面板：好友管理、发送时间/内容、高级设置、自启管理、实时日志
- 开机自启（启动文件夹快捷方式）：登录自动检查，完成即退出/未到点等待/错过补发
- 每日定时任务兜底触发（智能调度 + 进程锁防并发，非运行时段零进程零占用）
- 拟人化：随机延迟、逐字键入，降低风控概率
- 发送成功以「聊天窗口文本变化 + 输入框清空」双信号确认
- 找不到好友时自动「刷新页面 + 重进消息页」重试
- GPU 渲染可配置

## 源码运行（开发环境）

```bat
:: 1. 一键安装（创建独立 conda 环境 dy_spark + 下载浏览器）
app\scripts\install.bat

:: 2. 启动设置面板
app\scripts\start_gui.bat

:: 3. 首次扫码登录后，注册开机自启
面板「注册自启任务」
```

## 目录结构

```
app/
├─ app_launcher.py       # 统一入口（GUI / --run 任务模式）
├─ gui_qt.py             # PyQt5 设置面板
├─ main.py               # 主流程入口（智能调度）
├─ config.yaml           # 配置：好友、时间、内容、GPU 开关等
├─ modules/
│  ├─ login.py           # 登录态管理（sessionid 检测、扫码等待）
│  ├─ sender.py          # 进入消息页 → 定位好友 → 发送 + 成功确认
│  ├─ state.py           # 每日一次防重、发送记录
│  └─ logger.py          # 日志（logs/app.log）
└─ scripts/
   ├─ install.bat        # 一键安装
   ├─ start_gui.bat      # 启动面板
   ├─ run_now.bat        # 手动运行一次
   ├─ run_diag.bat       # 页面诊断
   └─ register_task.bat  # 注册/删除定时任务
```

## 注意事项

- 好友需在消息会话列表可见（与对方有过私信记录），填你对该好友的备注
- 网页版搜索为 AI 全网搜索，会跳转导致定位失败，故默认不启用搜索兜底
- 登录态保存在本机 data/profile，请勿分享该目录（含账号凭证）
- 网页版改版导致定位失效时，运行 `run_diag.bat` 并把 `diag_output.txt` 反馈
