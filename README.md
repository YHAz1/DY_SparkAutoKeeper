# DY_SparkAutoKeeper — 自动续火花工具

每天定时给指定好友发送 `[续火花吧]`，保持火花不断。纯本地运行，**非运行时段零进程、零性能占用**。

## 快速开始（打包版，无需安装环境）

1. 下载压缩包 `DY_SparkAutoKeeper_v1.1.0_win64.zip` 并解压
2. 双击 `app.exe` 打开设置面板
3. 首次使用：点「立即运行一次」扫码登录 → 之后自动复用登录态
4. 填入好友备注、设置发送时间，点「注册自启任务」

> 无数字签名，首次运行如出现 SmartScreen 警告，点「更多信息 → 仍要运行」。

## v1.1.0 相对 v1.0.4 的修复与优化

v1.0.4 在实际使用中暴露了几个核心问题，本版本彻底重写了好友定位引擎：

| v1.0.4 的弊端 | v1.1.0 修复方案 |
|---|---|
| **不能翻页**：只能定位会话列表顶部的好友（置顶 / 最近聊过的），实际上只有首屏可见的约 9 个好友能发成功；列表靠下的好友等 25 秒超时后直接失败 | 重写为 **JS 直接滚动会话列表容器逐屏扫描**：虚拟列表边滚边渲染新会话项，任意位置、任意数量的好友都能找到并打开 |
| **滚动滚错对象**：自动滚动滚的是抖音主页面而不是左侧/右侧会话列表 | 精准锁定会话列表自身的滚动容器（实测 DOM 结构），滚动只作用于列表 |
| **每个好友之间整页刷新，非常慢**：发完一个人就刷新整个页面重新进消息页，人均开销约 10 秒；且首次进入固定只等 6 秒，经常误判失败又整页重载，雪上加霜 | 点击"消息"后改为**轮询等待面板出现**（最长 30 秒），不再盲目重载；发完一个好友后**点返回按钮回到列表直接复用面板**，下一个人均只要约 3 秒 |
| **聊天窗口关不掉**：旧逻辑按 Esc 返回列表，但实测 Esc 对聊天页无效 | 改为点击聊天页左上角的**返回按钮**回列表（实测有效） |
| **搜索兜底跳转到 AI 全网搜索**：兜底逻辑误点页面顶部的全局搜索框，跳走后定位失败 | 只认**消息面板内部的搜索框**，输入备注名后在结果项里点「发消息」按钮直达私聊；绝不触碰全局 AI 搜索 |

实测数据：给列表靠下、首屏不可见的好友发送，滚动查找第 3 轮命中并发送成功（全程约 9 秒）；9 个好友演练模式全部通过，人均约 3 秒。

## 功能

- 每日自动给 1 个或多个好友发送 `[续火花吧]`（输入文本自动转为火花表情）
- PyQt5 设置面板：好友管理、发送时间/内容、高级设置、自启管理、实时日志
- 开机自启（启动文件夹快捷方式）：登录自动检查，完成即退出/未到点等待/错过补发
- 每日定时任务兜底触发（智能调度 + 进程锁防并发，非运行时段零进程零占用）
- 可选「每日任务后自动随机明日时间」（9:00-22:00 区间内随机）
- 拟人化：随机延迟、逐字键入，降低风控概率
- 发送成功以「聊天窗口文本变化 + 输入框清空」双信号确认
- 找不到好友时多重兜底：会话列表滚动查找 → 面板内搜索 → 刷新重试
- GPU 渲染可配置

## 源码运行（开发环境）

```bat
:: 1. 一键安装（创建独立 conda 环境 dy_spark + 下载浏览器）
app\scripts\install.bat

:: 2. 启动设置面板
app\scripts\start_gui.bat

:: 3. 首次扫码登录后，注册开机自启
面板「注册自启任务」
```

## 目录结构

```
app/
├─ app_launcher.py       # 统一入口（GUI / --run 任务模式）
├─ gui_qt.py             # PyQt5 设置面板
├─ main.py               # 主流程入口（智能调度）
├─ config.yaml           # 配置：好友、时间、内容、GPU 开关等
├─ diag.py               # 页面结构诊断脚本
├─ modules/
│  ├─ login.py           # 登录态管理（sessionid 检测、扫码等待）
│  ├─ sender.py          # 打开消息面板 → 滚动查找/搜索好友 → 发送 + 成功确认
│  ├─ state.py           # 每日一次防重、发送记录
│  └─ logger.py          # 日志（logs/app.log）
└─ scripts/
   ├─ install.bat        # 一键安装
   ├─ start_gui.bat      # 启动面板
   ├─ run_now.bat        # 手动运行一次
   └─ register_task.ps1/.bat  # 注册/删除定时任务
```

## 注意事项

- 好友需与对方有过私信记录（会话出现在消息列表里），填你对该好友的**备注名**
- 列表再靠下的好友也能找到（v1.1.0 起支持滚动查找），无需置顶
- 登录态保存在本机 data/profile，请勿分享该目录（含账号凭证）
- 网页版改版导致定位失效时，运行 `diag.py` 并把输出反馈给开发者
