# DY_SparkAutoKeeper — 抖音自动续火花工具

每天定时给指定好友发送 `[续火花]`，保持抖音火花不断。纯本地运行，**非运行时段零进程、零性能占用**（由 Windows 任务计划程序触发，发完即退）。

## 功能

- 每日自动给 1 个或多个好友发送 `[续火花]`（输入文本由抖音自动转为火花表情）
- tkinter 轻量配置面板：好友管理、发送时间/内容、立即运行、注册开机自启、实时日志
- 开机自启（启动文件夹快捷方式）：登录自动检查，完成即退出/未到点等待/错过自动补发
- 每日定时任务兜底触发（智能调度 + 进程锁防并发，非运行时段零进程零占用）
- 拟人化：随机延迟、逐字键入（适配 React 受控输入框），降低风控概率
- 发送成功以「聊天窗口文本变化 + 输入框清空」双信号确认，不误报
- 找不到好友时自动「刷新页面 + 重进消息页」重试，无需人工干预
- GPU 渲染可配置（显卡跑模型时可关闭）

## 环境要求

- Windows 10/11
- Anaconda（依赖安装严格使用独立环境 `dy_spark`，不污染 base）

## 安装与使用

```bat
:: 1. 一键安装（创建独立 conda 环境 + 下载浏览器）
app\scripts\install.bat

:: 2. 启动配置面板：填好友昵称（对方抖音昵称，需有私信记录）、发送时间
app\scripts\start_gui.bat

:: 3. 首次登录：面板点「立即运行一次」→ 浏览器弹出后扫码登录（之后自动复用登录态）

:: 4. 注册开机自启：面板点「注册开机自启任务」（每日自动发送）
```

## 目录结构

```
app/
├─ main.py              # 主流程入口（任务计划程序调用）
├─ gui.py               # tkinter 配置面板
├─ diag.py              # 页面结构诊断脚本（网页版改版排查用）
├─ config.yaml          # 配置：好友、时间、内容、GPU 开关等
├─ modules/
│  ├─ login.py          # 登录态管理（sessionid 检测、扫码等待）
│  ├─ sender.py         # 进入消息页 → 定位好友 → 发送 + 成功确认
│  ├─ state.py          # 每日一次防重、发送记录
│  └─ logger.py         # 日志（logs/app.log）
└─ scripts/
   ├─ install.bat       # 一键安装
   ├─ start_gui.bat     # 启动面板
   ├─ run_now.bat       # 手动运行一次
   ├─ run_diag.bat      # 页面诊断
   └─ register_task.bat # 注册/删除定时任务
```

## 注意事项

- 好友需在消息会话列表可见（与对方有过私信记录），昵称填对方抖音昵称
- 抖音网页版搜索为 AI 全网搜索，会跳转导致定位失败，故默认不启用搜索兜底
- 账号风控：一天一次低频 + 拟人化，风险极低；建议先用小号验证
- 网页版改版导致定位失效时，运行 `run_diag.bat` 并把 `diag_output.txt` 反馈
